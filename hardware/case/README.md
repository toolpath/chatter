# 3D printed case

A case for a Raspberry Pi that runs Chatter. It has 2 printed parts: the **Base** (bottom) and the **Housing** (top).

The case fits a Pi 3A+. To fit another Pi or device, change the design in the `.f3z` file.

| File | Use it to |
| --- | --- |
| `ChatterBox_3DPrintable.step` | Print the case. Many slicers open STEP files. If your slicer cannot, open the file in a CAD program and export an STL or 3MF file. |
| `ChatterBox_3DPrintable.f3z` | Change the design in Autodesk Fusion. It has the case and a model of the Pi 3A+. |

To close the case, you need 4 screws: [McMaster-Carr 90485A435](https://www.mcmaster.com/products/90485a435/).

See also [3D printed case](https://toolpath.github.io/chatter/hardware/case) in the docs.
